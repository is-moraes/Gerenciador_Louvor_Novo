Configurar YouTube

Configure o acesso à sua conta Google para criar playlists automaticamente.

  1. 1
    Acesse console.cloud.google.com, crie um projeto (ex: Ministerio Louvor) e ative a YouTube Data API v3 em "APIs e Serviços".
  2. 2
    Vá em Credenciais → Criar credencial → ID do cliente OAuth. Escolha Aplicativo da Web. Em "URIs de redirecionamento autorizados" adicione: e salve.
  3. 3
    Em Tela de consentimento OAuth adicione seu e-mail como usuário de teste. Isso permite usar o app sem publicá-lo.
  4. 4
    Copie o ID do cliente (Client ID) gerado e cole abaixo.

Salvo apenas neste navegador.

Configurar Spotify

Siga os passos abaixo para conectar sua conta pessoal. Feito uma vez, fica salvo no navegador.

  1. 1
    Acesse developer.spotify.com/dashboard e faça login com sua conta Spotify pessoal.
  2. 2
    Clique em "Create app". Preencha: Nome: Ministério de Louvor, Descrição: qualquer texto, Redirect URI: — clique em Add. Marque "Web API" e salve.
  3. 3
    Abra o app criado → Settings → copie o Client ID e cole abaixo.

O Client ID fica salvo apenas neste navegador, nunca enviado a servidores externos.
