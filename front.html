Como aproveitar o portal do ministério

Como ouvir as músicas?

Toque no botão vermelho para abrir o vídeo, no verde para o Spotify, ou no botão escuro com ▶ para tocar o repertório em sequência a partir daquela música. Em “Tocar Tudo” o repertório inteiro toca em ordem.

Onde ficam as cifras?

No botão amarelo de cada música. A cifra abre dentro do portal; se o site não permitir, um botão leva você para uma nova aba.

O que é o modo Treinar?

Quando a música tem vídeo e cifra, aparece o botão “Treinar”: a cifra ocupa a tela inteira e o vídeo fica em uma janela flutuante que você pode arrastar e redimensionar. Se a cifra estiver cadastrada em texto, você também pode trocar o tom ali mesmo.

Como usar o metrônomo?

Toque no botão azul da música para abrir o metrônomo já ajustado no BPM dela. Você pode alterar o andamento, o compasso ou usar o “Tap” para marcar no ritmo.

O que é um Medley?

É uma música com várias partes. Toque na etiqueta “Medley” para ver e abrir cada parte separadamente.

Como ver outra semana?

Use as setas no cartão do culto ou abra o menu “Cultos” para escolher entre as semanas com programação publicada.
